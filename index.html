knowledgebytes-pipeline

knowledgebytes-pipeline is a personal automation tool operated by a single user — its owner — to create and upload original educational short videos to the owner's own YouTube channel, knowledgeBytes.

What it does

The tool scripts, fact-checks, renders, and schedules short "now you know" educational videos. It accesses YouTube exclusively through the YouTube Data API using the owner's own OAuth authorization. It is not publicly accessible, has no other users, and touches no data belonging to any other person.

The channel

knowledgeBytes publishes bite-size, verified fun facts — science, history, how things work — with the goal that every video ends in "oh wow, I didn't know that."
