Privacy Policy — knowledgebytes-pipeline

Effective date: 20 August 2026

knowledgebytes-pipeline is a personal automation tool operated by a single user (its owner) to upload original videos to the owner's own YouTube channel.

  • The tool accesses YouTube exclusively through the YouTube Data API, using the owner's own OAuth authorization.
  • It does not collect, store, process, or share any data belonging to any other person.
  • The tool is not publicly accessible: no third party can use this tool.
  • It does not access viewer data, subscriber lists, or any personal information of YouTube users.
  • No data is sold, shared, or transferred to any third party.
  • OAuth credentials are stored locally on the owner's personal computer and are used solely to manage the owner's own channel content.

Google user data handled by this tool is limited to the owner's own YouTube channel content and analytics, accessed under the Google API Services User Data Policy, including its Limited Use requirements.
